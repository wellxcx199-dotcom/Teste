# ==========================================================================
#  População Híbrida - modificadores estáticos
#
#  O EU4 não aceita "imposto = população x 0,01" num modificador, então a
#  população é convertida em FAIXAS e cada faixa tem um bônus fixo.
#  Faixas neutras (rural 2 e urbana 1) não têm modificador nenhum: menos
#  modificadores ativos = menos recálculo e uma interface mais limpa.
#  Nome de arquivo próprio (pop_*) para NÃO sobrescrever o 00_event_modifiers
#  do jogo base.
# ==========================================================================
